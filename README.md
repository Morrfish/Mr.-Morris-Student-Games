# Mr. Morris' Game Closet

Digital board games made by and for Bluffton students. Open the closet, pick a box off the shelf, and play. No sign-in needed.

Play here: https://morrfish.github.io/Mr.-Morris-Student-Games/

- `index.html` is the closet
- `games/` holds one file per game
- `covers/` holds the box art

Game saves stay in each player's own browser.
